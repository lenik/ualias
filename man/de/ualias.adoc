== Name

ualias - USB-Gerätealiase nachschlagen oder anhängen

== Synopsis

*ualias* [_OPTION_]... [_SERIENNUMMER_ [_NAME_]]

== Description

Liest die Aliastabelle unter */etc/udev/ualias.d* (überschreibbar mit
*UALIAS_DIR*) und gibt den passenden Alias aus oder hängt bei Angabe eines
Namens ein neues Muster an.

Jede Nicht-Kommentarzeile der Datei hat vier Felder:

  VENDOR PRODUCT SERIAL NAME

Der Wert *\** ist ein Platzhalter. Zeilen werden in Dateireihenfolge geprüft;
der erste Treffer gewinnt. Spezifische Seriennummern stehen daher üblicherweise
vor einem Hersteller/Produkt-Fallback wie *303a 1001 \* s3g* für ESP32-S3.

Ohne *--name* (oder positionales _NAME_) wird der gefundene Alias auf die
Standardausgabe geschrieben. Ohne Treffer: Fehler und Exitstatus 1.

Mit einem Namen wird ein Muster angehängt. Fehlende Hersteller-, Produkt- oder
Serienfelder werden als *\** geschrieben.

== Options

*-w, --vendor* _ID_::
  USB-Hersteller-ID (typisch vier Hexziffern, ohne *0x*-Präfix).

*-p, --product* _ID_::
  USB-Produkt-ID (typisch vier Hexziffern, ohne *0x*-Präfix).

*-s, --serial* _SERIAL_::
  Geräteseriennummer oder MAC-ähnliche Kennung.
  Derselbe Wert kann als erstes Positionsargument angegeben werden.

*-n, --name* _NAME_::
  Aliasname. Ein Name aktiviert den Anhängemodus.
  Derselbe Wert kann als zweites Positionsargument angegeben werden
  (erfordert eine positionale Seriennummer).

*-u, --ucfirst*::
  Ersten Buchstaben des Aliasnamens großschreiben (Ausgabe oder beim Anhängen).

*-h, --help*::
  Kurzhilfe ausgeben und erfolgreich beenden.

*--version*::
  Versions- und Lizenzinformationen ausgeben und erfolgreich beenden.

== Environment

*UALIAS_DIR*::
  Pfad zur Gerätetabelle. Standard: */etc/udev/ualias.d*.

*UALIAS_LOCALEDIR*::
  Gettext-Locale-Verzeichnis überschreiben.

== Exit status

*0*::
  Erfolg.

*1*::
  Kein Treffer, fehlende Argumente oder E/A-Fehler.

*2*::
  Ungültige Kommandozeilenoptionen.

== Examples

Nachschlagen per Seriennummer:

  ualias 44:1B:F6:D7:92:5C

ESP32-S3 per Hersteller/Produkt, wenn die Seriennummer unbekannt ist
(Fallback auf *s3g*):

  ualias -w 303a -p 1001 -s DEADBEEF

Serienzuordnung anhängen:

  ualias 44:1B:F6:D7:92:5C s3cam

Hersteller/Produkt-Fallback anhängen:

  ualias -w 303a -p 1001 -n s3g

== Files

*/etc/udev/ualias.d*::
  Standard-Aliastabelle.
