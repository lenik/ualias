== Name

ualias - البحث عن أسماء مستعارة لأجهزة USB أو إلحاقها

== Synopsis

*ualias* [_خيار_]... [_تسلسلي_ [_اسم_]]

== Description

يقرأ جدول الأسماء المستعارة في */etc/udev/ualias.d* (يمكن تجاوزه بـ
*UALIAS_DIR*) ويطبع الاسم المطابق، أو يلحق نمطًا عند إعطاء اسم.

كل سطر غير تعليق في الملف له أربعة حقول:

  VENDOR PRODUCT SERIAL NAME

القيمة *\** حرف بدل. تُجرَّب الأسطر بترتيب الملف؛ أول تطابق يفوز. لذلك تُدرج
عادةً أرقام تسلسلية محددة قبل احتياطي البائع/المنتج مثل *303a 1001 \* s3g*
لـ ESP32-S3.

بدون *--name* (أو _الاسم_ الموضعي)، يُكتب الاسم المطابق إلى الخرج القياسي.
إن لم يوجد تطابق: خطأ ورمز خروج 1.

مع اسم، يُلحق نمط. حقول البائع أو المنتج أو التسلسلي المحذوفة تُكتب *\**.

== Options

*-w, --vendor* _ID_::
  معرّف بائع USB (عادةً أربع خانات ست عشرية، بلا *0x*).

*-p, --product* _ID_::
  معرّف منتج USB (عادةً أربع خانات ست عشرية، بلا *0x*).

*-s, --serial* _SERIAL_::
  الرقم التسلسلي أو معرّف بأسلوب MAC.
  يمكن إعطاء القيمة نفسها كأول وسيط موضعي.

*-n, --name* _NAME_::
  الاسم المستعار. اختيار اسم يفعّل وضع الإلحاق.
  يمكن إعطاء القيمة نفسها كثاني وسيط موضعي
  (يتطلب تسلسليًا موضعيًا).

*-u, --ucfirst*::
  جعل الحرف الأول من الاسم كبيرًا (في الخرج أو عند الكتابة أثناء الإلحاق).

*-h, --help*::
  طباعة ملخص الاستخدام والخروج بنجاح.

*--version*::
  طباعة الإصدار والترخيص والخروج بنجاح.

== Environment

*UALIAS_DIR*::
  مسار جدول الأجهزة. الافتراضي: */etc/udev/ualias.d*.

*UALIAS_LOCALEDIR*::
  تجاوز دليل مواقع gettext.

== Exit status

*0*::
  نجاح.

*1*::
  لا تطابق، أو وسائط ناقصة، أو خطأ إدخال/إخراج.

*2*::
  خيارات سطر أوامر غير صالحة.

== Examples

البحث بالتسلسلي:

  ualias 44:1B:F6:D7:92:5C

ESP32-S3 بالبائع/المنتج إذا كان التسلسلي مجهولًا (يعود إلى *s3g*):

  ualias -w 303a -p 1001 -s DEADBEEF

إلحاق تعيين تسلسلي:

  ualias 44:1B:F6:D7:92:5C s3cam

إلحاق احتياطي بائع/منتج:

  ualias -w 303a -p 1001 -n s3g

== Files

*/etc/udev/ualias.d*::
  جدول الأسماء المستعارة الافتراضي.
